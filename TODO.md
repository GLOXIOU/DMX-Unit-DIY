# Code:
* Entrée DMX/USB (mode "Enttec-like" en branchant l'ESP32-S3 en USB).
* Mode Wi-Fi / portail de configuration.
* Réponse **ArtPoll** (le boîtier n'apparaîtra pas automatiquement dans les
  logiciels de découverte Art-Net — il faut renseigner son IP manuellement,
  `192.168.1.77` par défaut dans ce sketch).
* Sauvegarde persistante des réglages (Preferences/EEPROM).
* RDM.
